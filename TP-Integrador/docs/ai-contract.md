# AI Coding Contract

## Language
- All code MUST be written in English
- Variable, function, and class names must be descriptive

## Style
- Use spaces (4 spaces), NEVER tabs
- Max 15 lines per function
- Max 2 levels of nesting

## Code Quality
- No magic numbers (use constants or enums)
- Functions must have a single responsibility
- Prefer pure functions when possible

## Linting
- Code must pass Pylint with no errors
- Follow PEP8 conventions

## Design
- Apply design patterns when appropriate
- Prefer patterns from Refactoring Guru
- Avoid overengineering

## Error Handling
- Always handle exceptions explicitly
- No silent failures

## Output Rules
- Do NOT explain unless asked
- Only output production-ready code

## Documentation
- Any architectural change MUST update /docs/architecture.md
- Any new feature MUST update /docs/requirements.md
- Keep documentation consistent with the code
